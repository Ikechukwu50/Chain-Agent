# ⛓️ ChainAgent

AI that watches your crypto and spends it for you.

## What it does

- Monitors 7 blockchains (BTC, ETH, SOL, TRX, etc.)
- AI decides when to spend based on your portfolio
- Books flights, hotels, subscriptions, gift cards automatically
- Sends daily reports

## Setup

1. Import `workflow.json` to n8n
2. Add wallet addresses + Groq API key
3. Connect Gmail
4. Run it

Built with n8n + Groq AI (LLaMA 3.3).
